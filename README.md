# Projeto Git Flow

## Descrição
Este projeto foi desenvolvido como atividade prática da disciplina de Git e GitHub, com o objetivo de praticar o controle de versão e a organização de arquivos.

## Instalação
1. Acesse o repositório no GitHub.
2. Clique em Code.
3. Copie o link do repositório.
4. Execute o comando:

git clone URL_DO_REPOSITORIO

## Uso
O projeto permite praticar funcionalidades do Git, como commits, branches, Issues, Pull Requests e arquivos de configuração.
